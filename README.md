# ⚡ SpeakFree (스픽프리)

> **OPIc 질문 연습 & 토익스피킹 기본 템플릿 트레이너**
> 420개의 실전 오픽 질문을 바탕으로, 즉흥 키워드 브레인스토밍부터 실전 녹음, 정밀 스크립트 작성까지 체계적으로 훈련할 수 있는 스피킹 특화 웹 애플리케이션입니다.

---

## 토익스피킹 만능문장 암기

**만능문장 암기** 탭은 Part 2·3·5 PDF를 바탕으로 문법·철자·자연스러운 표현·한국어 뜻을 교정한 학습 문장을 표시합니다. Part 2 149개, Part 3 50개, Part 5 61개 항목으로 총 260개입니다. Part 2 80번의 누락된 영어를 보완했고, Part 5의 불완전한 틀은 대괄호 슬롯으로 정리했습니다. 원본 PDF, 원문 셀, 원문 영어·한국어는 별도로 보존합니다.

**문장 익히기 → 테스트**로 연습합니다. 테스트에서 한국어를 보고 영어 문장을 소리 내어 말한 뒤 정답 확인으로 비교합니다. 다시 테스트를 누르면 정답이 숨겨집니다. 텍스트 답안 입력창은 제공하지 않습니다. 문장 듣기·3번 반복 듣기·검색·암기 상태 필터·번호순 목록·PDF 출처 링크를 제공합니다. 현재 PDF 페이지의 전체 노트도 확인할 수 있습니다. **다시 외울 문장** 탭은 현재 선택한 파트의 복습 항목만 보여줍니다. 위의 Part 2·3·5 버튼으로 각 파트의 복습 목록을 따로 선택하며, 파트 버튼에 각 복습 개수도 표시합니다. 외웠어요로 바꾸거나 복습 표시 해제로 목록에서 제외할 수 있습니다. 외웠어요 버튼은 같은 카드에서 다시 누르면 체크를 해제하며, 암기 개수와 필터 목록도 함께 갱신됩니다. 진도는 `speakfree_toeic_original_memory_v1`에 별도로 저장되고 JSON으로 백업·복원할 수 있습니다. 내 템플릿의 데이터나 기록은 변경하지 않습니다.

`extract_original_sentences.py`와 `build_original_sentences.py`로 PDF 표를 추출하며, 번호 누락과 원문 문자 보존을 검증합니다. 학습 데이터는 `toeic-sentences-data.js`, 화면은 `toeic-sentences.js`, 원본 사본은 `materials/toeic-original/`에 있습니다.

## 토익스피킹 내 템플릿

기본 템플릿은 모두 삭제했습니다. **＋ 새 템플릿**에서 Part 2~5의 제목, 질문 유형, 연습 질문, 상황, 메모와 답변 단계를 직접 작성하세요. 각 단계의 이름·한국어 힌트·영어 문장을 편집할 수 있으며 단계 추가·삭제·순서 변경도 가능합니다. 저장 전 취소하면 기존 템플릿을 유지합니다.

영어 문장에 `[이유]`, `[경험]`처럼 대괄호를 사용하면 **내 답변 만들기**에 해당 빈칸 입력창이 생깁니다. 같은 이름은 동일한 내용으로 채워집니다. **구조 익히기 → 내 답변 만들기 → 가리고 말하기**로 연습하고, 학습 카드의 **템플릿 수정**으로 언제든 내용을 바꾸세요. 수정 시 해당 템플릿의 암기 표시는 초기화되며 남아 있는 빈칸의 답변은 유지합니다.

삭제 직후 **삭제 취소**로 되돌릴 수 있습니다. 템플릿·답변·진도는 브라우저의 `speakfree_toeic_custom_templates_v1`에 저장됩니다. **템플릿·기록 백업 / 복원**으로 JSON 파일에 보관하고 옮길 수 있습니다. 기존 기본 템플릿 진도는 다음 접속 시 한 번만 제거하며 오픽 데이터는 유지합니다.

## 🚀 빠른 실행 방법 (Quick Start)

별도의 복잡한 패키지 설치(`npm install`) 없이 바로 실행할 수 있습니다.

### 방법 1. Node.js 로컬 서버로 실행 (가장 권장 ⭐)
브라우저 마이크 녹음(MediaRecorder) 권한 및 로컬 기능이 가장 안정적으로 동작합니다.

1. 터미널(PowerShell, CMD 등)을 열고 프로젝트 폴더로 이동합니다.
2. 다음 명령어를 입력하여 서버를 실행합니다:
   ```bash
   node server.js
   ```
3. 웹 브라우저(Chrome 또는 Edge 권장)를 열고 다음 주소로 접속합니다:
   ```
   http://localhost:3000
   ```
4. 서버를 종료하려면 터미널에서 `Ctrl + C`를 누릅니다.

---

### 방법 2. `index.html` 파일 직접 열기 (무설치 방식)
Node.js가 설치되어 있지 않거나 빠르게 화면을 확인하고 싶을 때 사용합니다.

1. 프로젝트 폴더 내의 **`index.html`** 파일을 더블 클릭합니다.
2. 기본 웹 브라우저(Chrome, Edge, Whale 등)로 자동 실행됩니다.
   *(또는 브라우저 창으로 `index.html` 파일을 드래그 앤 드롭)*

> 💡 **참고**: 일부 최신 브라우저의 보안 정책상 마이크 녹음 기능은 `http://localhost` 환경(방법 1)에서 가장 원활하게 동작합니다.

---

### 방법 3. VS Code Live Server 확장 사용
Visual Studio Code를 사용하는 경우:

1. VS Code에서 `Speak_Free` 폴더를 엽니다.
2. 확장(Extensions, `Ctrl+Shift+X`)에서 **Live Server**를 설치합니다.
3. `index.html` 파일을 우클릭한 후 **"Open with Live Server"**를 클릭합니다.

## 📌 주요 핵심 기능

- **420개 실전 OPIc 기출 문항 탑재**:
  - 총 30개 세트(Set 01 ~ Set 30) 및 16개 이상의 카테고리별 분류 (가구/주거, 음식/식당, 여행, 영화, 테크 등)
  - 질문 유형 자동 분류 (묘사/루틴, 롤플레잉, 과거비교/변화, 경험/돌발/이슈)
- **실전 타이머 & TTS 음성**:
  - 실제 시험과 유사한 **생각 시간 타이머** (15초, 30초, 45초, 60초 프리셋 지원)
  - 질문 텍스트를 원어민 발음으로 읽어주는 **TTS(Text-to-Speech)** 기능 (배속 조절 0.8x, 1.0x, 1.2x 지원)
- **실시간 음성 녹음 & 다시 듣기**:
  - 내 발화 음성을 직접 녹음하고 즉시 플레이어로 피드백 확인 가능
- **2단계 답변 빌드업 시스템**:
  - **1단계 키워드 태그 & 즉흥 메모**: 생각 시간 동안 핵심 키워드를 빠르게 입력하고 태그로 시각화
  - **2단계 정밀 스크립트 작성**: 글자 수/단어 수 실시간 계산 및 유형별 답변 구조 템플릿(경험담, 과거비교, 롤플레잉) 원클릭 삽입
- **진척도 트래킹 및 데이터 자동 저장**:
  - 작성한 모든 답변과 북마크는 브라우저 `localStorage`에 자동 보존 (새로고침해도 유지)
  - 전체 완료율 및 필터별 작성 현황 프로그레스 바 표시
- **데이터 백업 및 내보내기**:
  - 작성한 스크립트를 Markdown(`.md`), JSON, CSV 형식으로 저장
  - 저장된 백업 JSON 파일을 다시 불러오기(Import) 가능
- **다크 모드 / 라이트 모드** 지원

## ⌨️ 키보드 단축키 (Shortcuts)

키보드만으로 빠르게 넘어가며 실전처럼 훈련할 수 있습니다.

| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Ctrl + Enter`** | 변경 사항 자동 저장 후 **다음 질문으로 이동** |
| **`Ctrl + ←` / `Ctrl + →`** | 이전 / 다음 질문 이동 |
| **`Ctrl + Space`** | 생각 시간 **타이머 시작 / 일시정지** |
| **`Alt + L`** | 질문 텍스트 **원어민 음성(TTS) 듣기** |
| **`Alt + R`** | **무작위(랜덤) 질문** 출제 |
| **`Alt + B`** | 현재 질문 **북마크 토글 (즐겨찾기)** |

## 🎯 추천 실전 트레이닝 루틴

1. **질문 확인 및 청취**:
   - `Alt + L`을 눌러 질문 음성을 듣고 핵심 질문 포인트를 파악합니다.
2. **30초 즉흥 키워드 스케치 (1단계)**:
   - `Ctrl + Space`로 타이머를 시작하고, 1단계에 떠오르는 단어/표현 3~4개를 태그나 빠른 메모로 적습니다.
3. **실전 녹음**:
   - `녹음 시작` 버튼을 누르고, 작성한 키워드만 보면서 1분 ~ 1분 30초 동안 소리 내어 말해봅니다.
4. **모니터링 & 스크립트 보완 (2단계)**:
   - 녹음된 음성을 직접 들으며 아쉬웠던 표현, 어색한 문법, 고급 접속사 등을 2단계 정밀 스크립트 창에 정리합니다.
5. **다음 질문으로 이동**:
   - `Ctrl + Enter`를 눌러 다음 문제로 넘어가 연속 트레이닝을 진행합니다.

## 🛠️ 질문 데이터 수정 및 추가 방법

새로운 문제 세트나 추가 질문을 등록하고 싶다면:

1. `raw_questions.csv` 파일을 엑셀이나 텍스트 편집기로 엽니다.
2. 동일한 형식(`ID,Set,Order,Source_Number,Question_Text`)으로 질문 행을 추가/수정합니다.
3. 터미널에서 데이터 변환 스크립트를 실행합니다:
   ```bash
   node convert.js
   ```
4. `questions.js`가 자동으로 갱신되어 앱에 즉시 반영됩니다.

## 📁 프로젝트 파일 구조

```text
Speak_Free/
├── index.html          # 메인 UI 구조 및 마크업
├── style.css           # 모던 글래스모피즘 디자인 시스템 & 다크/라이트 테마
├── app.js              # 핵심 애플리케이션 상태 관리 및 사용자 인터랙션
├── questions.js        # 420개 OPIc 질문 데이터셋 (JS)
├── raw_questions.csv   # 원본 질문 데이터 (CSV)
├── convert.js          # CSV -> questions.js 변환 빌드 스크립트
├── server.js           # 초경량 Node.js 로컬 웹 서버 (무설치 내장 모듈)
└── README.md           # 프로젝트 안내 및 실행 가이드 문서
```

`correct_toeic_sentences.js`는 검토한 교정 문구를 적용합니다. 데이터 재생성 시에도 실행되며, 문장 ID와 기존 복습·암기 진도를 유지합니다. 테스트에서 스페이스바는 정답을 표시하고, 좌우 방향키는 문장을 이동합니다.

## 로컬 파일 자동 저장

`node server.js`로 실행하면 내 템플릿·빈칸 답변·암기 진도와 만능문장 복습·암기 기록을 프로젝트 폴더의 `toeic_records.json`에 자동 저장합니다. 처음 접속할 때 기존 브라우저 기록을 옮기며, 이후 접속 시 파일 기록을 불러옵니다. 브라우저 저장도 함께 유지합니다. 파일 저장 실패 시 상태를 표시하고 재시도합니다. `index.html`을 직접 열면 브라우저 저장만 사용합니다. 템플릿 편집은 저장 버튼을 눌러 확정한 내용이 보관됩니다.

## 만능 템플릿 암기

만능 템플릿 탭은 제공된 자료의 Part 2·3·4·5와 Part 3·5 공용 표현을 45개 카드로 제공합니다. 구조 익히기·가리고 말하기·검색·암기 상태 필터·듣기·백업과 복원을 지원합니다. 암기 기록은 speakfree_toeic_universal_memory_v1에 독립적으로 저장하고 toeic_records.json에도 자동 저장합니다.

만능 템플릿은 새 만능 템플릿 버튼으로 추가하고, 카드의 템플릿 수정·삭제 버튼으로 관리합니다. 파트·제목·분류·영어 템플릿·학습 메모를 편집하며 저장 전 취소하면 기존 내용을 유지합니다. 삭제 취소는 마지막 삭제를 현재 화면에서 되돌립니다. 편집한 목록은 speakfree_toeic_universal_templates_v1과 로컬 파일에 저장하고 재접속 시 복원합니다. 템플릿·암기 기록 백업은 편집 내용과 암기 기록을 함께 보관하며, 전체 복원은 백업 목록으로 교체합니다. 기존 암기 기록 백업도 복원할 수 있습니다.
